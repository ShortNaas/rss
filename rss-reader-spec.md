# Personal RSS Reader — Build Spec

Stack: Next.js (App Router) + Vercel + Neon (Postgres) + Vercel Cron

## Goals
- Single-user, no auth needed (or basic password gate)
- Add/remove feeds via URL
- Fetch feeds: (a) on manual refresh click, (b) via cron 1-2x/day
- List articles, mark read/unread, open original link
- Deploy free on Vercel Hobby + Neon free tier

## Tech Choices
- Framework: Next.js 14+ (App Router, Route Handlers for API)
- DB: Neon Postgres (serverless driver: `@neondatabase/serverless`)
- ORM: Drizzle ORM (lightweight, edge-compatible) — or raw SQL if preferred
- Feed parsing: `rss-parser` (npm)
- Styling: Tailwind CSS
- Hosting: Vercel (Hobby tier)
- Scheduling: `vercel.json` cron → hits a Route Handler

## Database Schema (Drizzle, Postgres)

```ts
// lib/schema.ts
import { pgTable, serial, text, timestamp, boolean, integer } from 'drizzle-orm/pg-core';

export const feeds = pgTable('feeds', {
  id: serial('id').primaryKey(),
  url: text('url').notNull().unique(),
  title: text('title'),
  siteUrl: text('site_url'),
  lastFetchedAt: timestamp('last_fetched_at'),
  createdAt: timestamp('created_at').defaultNow(),
});

export const articles = pgTable('articles', {
  id: serial('id').primaryKey(),
  feedId: integer('feed_id').notNull().references(() => feeds.id, { onDelete: 'cascade' }),
  guid: text('guid').notNull(),        // dedup key (falls back to link if no guid)
  title: text('title'),
  link: text('link'),
  content: text('content'),
  publishedAt: timestamp('published_at'),
  isRead: boolean('is_read').default(false),
  createdAt: timestamp('created_at').defaultNow(),
});

// Unique constraint on (feedId, guid) to prevent duplicate inserts on refetch
```

## Core Fetch Logic

```ts
// lib/fetchFeeds.ts
import Parser from 'rss-parser';
import { db } from './db';
import { feeds, articles } from './schema';
import { eq } from 'drizzle-orm';

const parser = new Parser();

export async function refreshAllFeeds() {
  const allFeeds = await db.select().from(feeds);
  const results = [];

  for (const feed of allFeeds) {
    try {
      const parsed = await parser.parseURL(feed.url);
      for (const item of parsed.items) {
        const guid = item.guid || item.link || item.title || '';
        await db.insert(articles).values({
          feedId: feed.id,
          guid,
          title: item.title,
          link: item.link,
          content: item.contentSnippet || item.content,
          publishedAt: item.pubDate ? new Date(item.pubDate) : null,
        }).onConflictDoNothing({ target: [articles.feedId, articles.guid] });
      }
      await db.update(feeds)
        .set({ lastFetchedAt: new Date(), title: feed.title || parsed.title })
        .where(eq(feeds.id, feed.id));
      results.push({ feed: feed.url, status: 'ok' });
    } catch (err) {
      results.push({ feed: feed.url, status: 'error', error: String(err) });
    }
  }
  return results;
}
```

## API Routes (behavior summary)

| Route | Method | Purpose |
|---|---|---|
| `/api/feeds` | GET | list all feeds |
| `/api/feeds` | POST | add feed by URL (validate + parse once to get title) |
| `/api/feeds/[id]` | DELETE | remove feed + its articles (cascade) |
| `/api/articles` | GET | list articles, filters: `feedId`, `unread=true` |
| `/api/articles/[id]/read` | POST | toggle/set read state |
| `/api/refresh` | POST | manually trigger `refreshAllFeeds()` immediately |
| `/api/cron/refresh` | GET | same as above, called by Vercel Cron; verify `Authorization` header matches `CRON_SECRET` |

## vercel.json (cron config)

```json
{
  "crons": [
    {
      "path": "/api/cron/refresh",
      "schedule": "0 7,19 * * *"
    }
  ]
}
```
Runs at 7am and 7pm UTC daily (adjust to taste). Hobby plan allows daily-granularity crons; exact time-of-day support varies — check current Vercel cron docs at deploy time.

## Cron Route Security

```ts
// app/api/cron/refresh/route.ts
export async function GET(req: Request) {
  const auth = req.headers.get('authorization');
  if (auth !== `Bearer ${process.env.CRON_SECRET}`) {
    return new Response('Unauthorized', { status: 401 });
  }
  const results = await refreshAllFeeds();
  return Response.json({ results });
}
```
Vercel automatically sends this header for cron-triggered requests when `CRON_SECRET` env var is set.

## Setup Steps

1. `npx create-next-app@latest rss-reader --typescript --tailwind --app`
2. Create Neon project → copy pooled connection string → set `DATABASE_URL`
3. `npm install drizzle-orm @neondatabase/serverless rss-parser`
4. `npm install -D drizzle-kit`
5. Write `lib/schema.ts`, run `npx drizzle-kit generate` then `npx drizzle-kit migrate`
6. Build API routes per table above
7. Build minimal UI: feed sidebar + article list + refresh button calling `/api/refresh`
8. Add `vercel.json` cron config + `CRON_SECRET` in Vercel env vars
9. `vercel deploy` (or connect GitHub repo for auto-deploy)
